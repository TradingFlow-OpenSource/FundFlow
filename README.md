# FundFlow

A Web3 fund management platform.

## Project Structure

```
FundFlow/
├── frontend/          # React + Vite + TypeScript 前端应用
│   ├── src/
│   │   ├── components/  # 可复用组件
│   │   ├── pages/       # 页面组件
│   │   └── ...
│   └── package.json
├── backend/           # 后端 API 服务
│   └── src/
├── contracts/         # 智能合约
│   └── src/
└── README.md
```

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend will be available at `http://localhost:3000`
